Reporting bugs Please report issues at github.com/KayhanB21/folder-filter-scheduler/issues. The fastest way to get a problem fixed: open the options page, expand Diagnostics at the bottom, press Copy report, and paste it into the issue along with what you expected to happen. The report hides your addresses and patterns by default. Known limitations
  • Requires Thunderbird 147 or newer. Older versions stay on 0.1.1, which needs 128 or newer.
  • Conditions on Reply-To and other non-indexed headers need the message available locally. For an IMAP folder, enable offline storage (Account Settings, Synchronization and Storage) for that folder, then run Repair Folder once.
  • Scheduled runs pick up new mail using each message's Date header, which the sender controls. A backdated message is caught by the catch-up scan, which runs every 30 minutes by default, so it can be delayed by up to that long. The interval is adjustable under Advanced. Mail backdated by more than the catch-up lookback is only caught by "Run all rules now", which scans the whole folder.
  • Address-book conditions read local address books only. LDAP directories cannot be listed, so they are not offered.
  • A rule may carry only one action that moves or deletes the message, since the first such action invalidates the message ids the rest would need.
  • The store validator may show warnings for Thunderbird mail permissions such as messagesMove. These are expected: the validator is shared with Firefox, which does not have mail permissions. They do not affect the add-on.
Planned for future versions

  • Per-rule schedule intervals
  • Translations for the options page, which is English only today
