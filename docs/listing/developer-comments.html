Reporting bugs Please report issues at github.com/KayhanB21/folder-filter-scheduler/issues. Including your Thunderbird version, the rule you configured, and what you expected to happen makes problems much faster to fix. Known limitations
  • Requires Thunderbird 147 or newer. Older versions stay on 0.1.1, which needs 128 or newer.
  • Conditions on Reply-To and other non-indexed headers need the message available locally. For an IMAP folder, enable offline storage (Account Settings, Synchronization and Storage) for that folder, then run Repair Folder once.
  • Scheduled runs pick up new mail using each message's Date header, which the sender controls. A backdated message can slip past a scheduled run. "Run all rules now" scans the whole folder and will catch it.
  • The store validator may show warnings for Thunderbird mail permissions such as messagesMove. These are expected: the validator is shared with Firefox, which does not have mail permissions. They do not affect the add-on.
Planned for future versions
  • Multiple actions per rule (for example, mark as read and move)
  • Conditions on the message body
