Translates the interface into 7 languages, and fixes runs that stopped after a rule archived thousands of messages.
  • New: the settings page, the toolbar popup, the Add spam domains window, and the right-click menu show in German, Spanish, French, Italian, Japanese, Korean, or Simplified Chinese. Thunderbird picks the language of its own interface. Any other language shows English
  • Fixed: move, copy, archive, and delete hand Thunderbird at most 200 messages per call. One archive of about 2600 messages never answered, so the rules after it didn't run until the next run
  • New: when an action needs more than one call, the diagnostics log records each one, such as rule "Work": archive 400 of 2609
