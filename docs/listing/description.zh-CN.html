文件夹过滤器调度器会按计划在任意文件夹上自动运行您的邮件过滤规则。Thunderbird 只会在收件箱上自动运行过滤器，因此邮件服务商在服务器端归入“垃圾邮件”或“Bulk”文件夹的邮件，以及存放在其他文件夹中的任何邮件，都不会被过滤。本附加组件弥补了这一不足。 功能
  • 在您选择的任意文件夹上运行规则，不仅限于收件箱
  • 按定时器运行、在收到新邮件时运行、按规则自己的 cron 计划运行，或一键立即运行
  • 一条规则可同时作用于多个账户
  • 可以包含文件夹的所有子文件夹，包括以后创建的子文件夹
  • 只需右键单击，即可根据已有的垃圾邮件建立发件人域名黑名单
  • 检查 SPF、DKIM 和 DMARC，并自行验证 DKIM 签名
屏蔽垃圾邮件域名 在邮件列表的任意位置选中垃圾邮件，右键单击，选择“文件夹过滤器调度器”，然后选择“添加垃圾邮件域名”。本附加组件会从 Reply-To 和 From 中读取发件人域名，分组显示供您检查，然后将其添加到一条规则中，该规则会按常规计划将匹配的邮件移到“已删除”。子域名会自动涵盖，因此屏蔽 evil.com 也会拦截 bounce.evil.com。Gmail、Yahoo、Outlook 和 iCloud 等知名邮件服务商永远不会被屏蔽，这份受保护的列表可以由您自行编辑。 检查 SPF、DKIM 和 DMARC 根据邮件是否通过 SPF、DKIM 或 DMARC 进行匹配，用于“将未通过 DMARC 的邮件移到垃圾邮件文件夹”之类的规则。本附加组件会读取邮件服务商添加的 Authentication-Results 邮件头。发件人可以伪造该邮件头，因此本附加组件还会自行验证 DKIM 签名，并根据两种结果推算 DMARC。每封邮件只检查一次，结果最多保留 90 天。“高级”中的设置用于选择 DNS 服务器、两种结果不一致时以哪个为准，以及信任哪些服务器的邮件头。DKIM 代码来自 Philippe Lieser 的 DKIM Verifier。 条件 可以按发件人、收件人、抄送、主题、Reply-To、List-Id 或发送者进行匹配，使用“包含”“是”“开头是”“结尾是”或“匹配正则表达式”。可以按邮件的存在时长进行匹配，使用“超过”或“少于” N 天，用于“30 天后将提醒邮件移到归档”之类的规则。可以检查发件人或“收件人”“抄送”中的任一收件人是否在您的某个通讯录中，或不在任何通讯录中。可以识别发件人名称中显示的地址与真实地址域名不同的情况，这是一种常见的垃圾邮件伎俩。可以检查邮件是否已读、是否已加星标或被标记为垃圾邮件，是否带有您的某个标签，优先级是什么，以及是否通过 SPF、DKIM 或 DMARC。每个条件都可以取反，并用“且”或“或”组合。单个条件还可以包含整个域名列表，右键操作填写的就是这种列表。 操作
  • 移到“已删除”，并分别送往每封邮件所属账户
  • 归档，使用各账户自己的归档设置，与 Thunderbird 的“归档”按钮相同
  • 移动或复制到任意文件夹，包括其他账户中的文件夹
  • 添加您的某个 Thunderbird 标签，并保留邮件上已有的标签
  • 标记为已读或未读，添加或移除星标，标记为垃圾邮件或非垃圾邮件
  • 永久删除
一条规则可以包含多个操作，因此“添加‘好友’标签并移到‘好友’文件夹”只需一条规则。无论您以什么顺序排列，移动或删除邮件的操作总是最后运行，因此其他操作仍能处理该邮件。 备份及在配置文件之间迁移 规则可以导出为 JSON 文件，并可重新导入。已有的规则会被识别并跳过，不会重复，因此导入共享的文件是安全的。 规则何时运行 规则按您设置的定时器运行，也会在新邮件到达受监视的文件夹后几秒内运行。到达的邮件会被分组处理，因此一次邮件同步只触发一次运行，并且只检查监视收到邮件的文件夹的规则。规则也可以有自己的计划，用 cron 表达式编写，例如 0 21 * * * 表示每天 21:00。这样，该规则只在这些时间运行；如果 Thunderbird 关闭期间错过了某次运行，会在下次启动时补上。要手动运行规则，请使用工具栏按钮、右键菜单或规则上的“运行”按钮。在设置页面的“高级”部分，您可以关闭新邮件触发，并调整扫描时间参数。 速度，以及关于 Reply-To 针对发件人、收件人、抄送和主题的条件使用已索引的数据，不下载任何内容。针对 Reply-To 或其他未索引邮件头的条件需要邮件本身，在线 IMAP 文件夹会按需获取邮件。为了提高速度并支持离线使用，请为该文件夹启用离线存储。计划运行只检查上次运行以来到达的邮件，另外每 30 分钟进行一次范围更大的补漏扫描，以处理 Date 邮件头晚于实际到达时间的邮件，因此大型文件夹的开销也很低。“立即运行所有规则”总是扫描全部邮件。 隐私 本附加组件不收集或出售任何数据，也没有分析或遥测功能。规则在 Thunderbird 内本地运行，邮件内容永远不会离开您的设备。除您自己的邮件服务器外，本附加组件唯一联系的服务器是用于可选 DKIM 检查的 DNS 服务器，并且只对含有 SPF、DKIM 或 DMARC 条件的规则运行。它会将 selector._domainkey.example.com 和 _dmarc.example.com 等域名的 DNS 查询发送到 Cloudflare 或 Google（由您选择），并且只在您允许之后才发送。通讯录和标签列表的访问权限是可选的，只有当您使用需要它们的条件或操作时，本附加组件才会请求。诊断报告只会由您自己分享，并且除非您选择包含，否则会隐藏地址、域名、匹配模式和文件夹名称。 开源 采用 MPL-2.0 许可证。欢迎前往 github.com/KayhanB21/folder-filter-scheduler 查看源代码、提交问题和参与贡献
