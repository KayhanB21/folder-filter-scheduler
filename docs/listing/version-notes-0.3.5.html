Subfolders, a searchable folder list, and a theme switch.
  • Include subfolders: a rule can watch a folder and every folder under it, including ones you create later. Trash folders and the rule's own move or copy destinations are skipped
  • The folder list is a tree, grouped by account and joined by dashed guide lines, and it marks the subfolders a rule includes
  • A filter box narrows the folder list, and "Select all matching" picks every match. Folders you picked earlier stay picked
  • A theme switch on the options page: Light, Dark, or System, which follows Thunderbird and is the default
