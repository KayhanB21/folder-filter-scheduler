Adds collapsible accounts and folders in the folder list, and fixes three display problems on the options page.
  • New: click an account name in the folder list to hide or show its folders. A folder with subfolders shows an arrow that hides or shows them. A collapsed account or folder names how many selected folders it hides. Expand and Collapse buttons open or close them all at once
  • New: the diagnostics log counts how many messages passed, didn't pass, or stayed unknown for SPF, DKIM, and DMARC
  • Save stops when an enabled rule has no folder, because that rule scans nothing. A disabled rule still saves
  • Trusted authentication servers under Advanced take one name per line. A list saved with commas still works
  • Operators that don't fit the chosen field move to the end of the menu, under "Works with other fields"
  • The delete button stays on the condition row
  • Header names such as Authentication-Results and the example addresses in the hints show in a monospace font, not a serif font
