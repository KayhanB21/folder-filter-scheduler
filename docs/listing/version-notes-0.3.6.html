Fixes for scheduled runs, a schedule for each rule, and a Run button on each rule.
  • New: a rule can have its own schedule, written as a cron expression such as "0 21 * * *" for 21:00 every day. It is off by default. The rule card describes the expression in plain words and shows the next run time
  • New right-click menu "Folder Filter Scheduler" with "Add spam domains", "Run all rules now", and "Run a rule"
  • New toolbar button that runs all rules or one rule
  • New "Run" button on each rule. It runs only that rule, on every message in its folders
  • New conditions: read or unread, starred or not, junk or not, and has a tag
  • New actions: "Mark as unread", "Remove star", and "Mark as not junk". "Flag" is now named "Add star"
  • New condition "name shows a different address". It matches a sender name that contains an email address from a different domain than the real address, which is common in spam. No rule uses it until you add it
  • A sender name that contains an email address no longer hides the real sender. Domain lists, "Add spam domains", and address-book checks read the real address
  • New mail no longer restarts the schedule timer, so scheduled runs happen on time even when mail arrives often
  • A header download that never answers no longer blocks a run. Each download has a 7-second limit
  • The diagnostics log shows when each run starts
  • New "Common problems" section on the options page. It explains why a rule can miss mail in Sent or other IMAP folders, and which Thunderbird setting fixes it
