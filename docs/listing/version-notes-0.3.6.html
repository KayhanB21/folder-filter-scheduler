Fixes for scheduled runs, a schedule for each rule, and a Run button on each rule.
  • New: a rule can have its own schedule, written as a cron expression such as "0 21 * * *" for 21:00 every day. It is off by default. The rule card describes the expression in plain words and shows the next run time
  • New "Run" button on each rule. It runs only that rule, on every message in its folders
  • New mail no longer restarts the schedule timer, so scheduled runs happen on time even when mail arrives often
  • A header download that never answers no longer blocks a run. Each download has a 5-second limit
  • The diagnostics log shows when each run starts
  • New "Common problems" section on the options page. It explains why a rule can miss mail in Sent or other IMAP folders, and which Thunderbird setting fixes it
