Common problems

A rule misses mail in Sent or another folder that isn't the Inbox

For IMAP accounts, Thunderbird checks only the Inbox for new mail by default. The add-on can process only messages that Thunderbird has downloaded, so mail that another program sends through your account, or that a server rule files, waits until you open the folder. Run all rules now seems to work because you opened the folder first.

To fix this, right-click the folder and open Properties. On the General tab, turn on When getting new messages for this account, always check this folder.

Mail arrived while Thunderbird was closed

Rules run only while Thunderbird is running. After Thunderbird starts, the first scheduled run checks the last 30 days, or the number of days set under Advanced, and processes anything it missed.

Something else doesn't work

Open Diagnostics and attach the report to a GitHub issue. The report shows what each recent run scanned and matched.
