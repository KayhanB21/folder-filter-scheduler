# Vendored libraries

The add-on bundles these third-party libraries as unchanged copies of the
published npm releases. Each URL points to the exact file the copy came from.

src/auth/thirdparty/psl/psl.mjs:
 - Version: 1.15.0
 - URL: https://cdn.jsdelivr.net/npm/psl@1.15.0/dist/psl.mjs
 - License: MIT, in `src/auth/thirdparty/psl/LICENSE`

src/auth/thirdparty/dns-message/dns-message.mjs:
 - Version: 1.1.1
 - URL: https://cdn.jsdelivr.net/npm/dns-message@1.1.1/dist/dns-message.mjs
 - License: MIT, in `src/auth/thirdparty/dns-message/LICENSE.md`

The code ported from DKIM Verifier is listed in
[`src/auth/THIRDPARTY_LICENSE.md`](src/auth/THIRDPARTY_LICENSE.md).
